Euphoria / Site guide

Euphoria saytının ümumi izahı

Bu sənəd saytın nə məqsədlə hazırlandığını, istifadəçinin səhifələr arasında necə hərəkət etdiyini və layihənin texniki olaraq necə qurulduğunu sadə dildə izah edir.

Layihə: Euphoria E-commerce
Frontend: Next.js, TypeScript, Tailwind CSS
Hazırlanmış səhifələr: Ana səhifə, kateqoriyalar, məhsul detalları, səbət, checkout, hesab və authentication

1. Sayt nə üçündür?

Euphoria geyim və gündəlik moda məhsullarını təqdim edən e-commerce saytıdır. Dizaynın əsas məqsədi məhsulu ön plana çıxarmaq, istifadəçiyə kateqoriyalar arasında rahat keçid vermək və alış prosesini qısa saxlamaqdır.

Sadə naviqasiyaHeader-də Shop, Men, Women, Combos və Joggers bölmələri var.
Məhsul kəşfiNew Arrival, Deals, kateqoriya kartları və Trending bölmələri məhsul seçimlərini asanlaşdırır.
Alış prosesiMəhsul detail səhifəsindən ölçü və rəng seçilib səbətə əlavə olunur.
Hesab idarəsiLogin, register, hesab məlumatları və wishlist səhifələri mövcuddur.

İstifadəçinin tipik yolu

1
Sayta daxil olur
Ana səhifədə hero banner və seçilmiş məhsullara baxır.
2
Kateqoriya seçir
Women, Men və ya digər bölmələrdən məhsul siyahısına keçir.
3
Məhsulu araşdırır
Şəkilləri, qiyməti, ölçüləri, rəngi və məhsul təsvirini görür.
4
Sifarişi tamamlayır
Məhsulu səbətə əlavə edib checkout formasını doldurur.

2. Saytdakı səhifələr

Səhifəİstifadə məqsədi
Ana səhifəHero banner, yeni məhsullar, kampaniyalar, qadın/kişi kateqoriyaları və trend məhsullar.
Shop / Women / MenMəhsulların grid şəklində göstərilməsi, kateqoriya sidebar-ı və qiymət/rəng filter görünüşü.
Combos / JoggersSeçilmiş məhsul qruplarını ayrıca təqdim edən kateqoriya səhifələri.
Product detailGallery, məhsul adı, brand, rating, qiymət, ölçü, rəng, quantity və səbətə əlavə etmə.
Cart / Empty cartSəbətdəki məhsullar, quantity idarəsi, silmə, subtotal və ümumi məbləğ.
CheckoutBilling details, shipping method, payment formu və order summary.
Login / Registerİstifadəçinin mock hesab yaratması və hesaba daxil olması.
My Account / WishlistProfil məlumatları, order history görünüşü və yadda saxlanılan məhsullar.
Bütün səhifələr responsive hazırlanıb. Desktop-da geniş grid və sidebar, mobil cihazlarda isə iki sütunlu məhsul görünüşü və açılan menyu istifadə olunur.

3. Sayt necə işləyir?

Login və Register

İstifadəçi login səhifəsində düzgün email və minimum 8 simvolluq şifrə daxil etdikdə mock hesab aktiv olur və account səhifəsinə yönləndirilir. Register zamanı ad, soyad və email məlumatları götürülür. Bu məlumatlar brauzerin localStorage yaddaşında saxlanılır.

Səbət

Məhsul detail və wishlist səhifəsindəki Add to cart düyməsi səbətə məhsul əlavə edir. Header-də ümumi məhsul sayı görünür. Səbətdə plus/minus ilə quantity dəyişir, zibil qutusu ilə məhsul silinir. Səhifə yenilənsə belə səbət məlumatı qorunur.

Checkout

Checkout səhifəsində istifadəçidən ünvan, shipping və kart məlumatları üçün form sahələri alınır. Hazırkı versiya frontend təqdimatı üçün mock-dur; real ödəniş provider-i qoşulmayıb.

4. Texniki quruluş

Layihə Next.js App Router ilə hazırlanıb. Ortada ümumi layout var; Header, Footer, cart və auth provider bütün route-larda paylaşılır.

src/app/          səhifə route-ları
src/components/   Header, Footer, Card, Cart, Auth və UI hissələri
src/lib/           ortaq məhsul datası
tailwind.config.ts dizayn tokenləri
next.config.mjs   şəkil domeni konfiqurasiyası
Next.jsRoute sistemi, static product pages və production build üçün.
TypeScriptMəhsul, istifadəçi və cart məlumatlarının tiplənməsi üçün.
Tailwind CSSResponsive utility class-lar və Figma rəng tokenləri üçün.
Lucide ReactSearch, heart, cart, user, menu və digər ikonlar üçün.
