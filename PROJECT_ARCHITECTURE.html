Euphoria / E-commerce

Layihənin texniki arxitekturası

Responsive geyim mağazası üçün hazırlanmış frontend sənədi. Bu sənəd layihənin qovluq quruluşunu, səhifə axınlarını və əsas texniki qərarları qısa və praktik şəkildə izah edir.

Versiya: Final təqdimat versiyası
Texnologiya: Next.js App Router, TypeScript, Tailwind CSS
Hazırlanma məqsədi: Figma dizaynının real web interfeysə çevrilməsi

1. Layihənin ümumi quruluşu

Layihə Next.js-in App Router arxitekturası üzərində qurulub. Səhifələr route fayllarında, təkrar istifadə olunan UI elementləri isə komponent qovluğunda saxlanılır. Beləliklə, yeni kateqoriya və ya məhsul əlavə etmək üçün eyni kodu təkrar yazmaq lazım deyil.

src/
  app/                 route və layout faylları
  components/          təkrar istifadə olunan UI komponentləri
  lib/                 məhsul datası və köməkçi funksiyalar
public/                lokal statik assetlər üçün qovluq
tailwind.config.ts     rəng, font, radius və shadow tokenləri
next.config.mjs        remote image konfiqurasiyası

Əsas prinsip

App RouterHər səhifə öz app/.../page.tsx faylı ilə idarə olunur. Ümumi Header və Footer layout.tsx daxilindədir.
Component-based UIProductCard, CatalogPage, AuthPage, CartPage və ProductDetails kimi komponentlər bir neçə səhifədə istifadə edilir.
TypeScriptProduct, CatalogProduct, MockUser və CartItem tipləri məlumat axınının səhvsiz qalmasına kömək edir.
Responsive designMobil, tablet və desktop ölçüləri Tailwind breakpoint-ləri ilə ayrıca nəzərə alınıb.

3. Məlumat və state idarəsi

Məhsul datası

Bütün demo məhsullar src/lib/products.ts faylında saxlanılır. Hər məhsulun slug, ad, brand, qiymət, kateqoriya, şəkil və təsvir məlumatı var. Kataloq, wishlist, cart və detail səhifələri eyni mənbədən istifadə edir.

Mock authentication

AuthContext login və register nəticəsini euphoria-user açarı ilə browser localStorage-da saxlayır. Login ekranında istənilən düzgün email və minimum 8 simvolluq şifrə demo hesabına giriş yaradır. Register formundakı ad və soyad account ekranında göstərilir.

Cart state

CartContext məhsul əlavə etmə, quantity dəyişmə və silmə əməliyyatlarını bütün səhifələr arasında paylaşır. Səbət euphoria-cart açarı ilə qorunur və header-də məhsul sayı göstərilir.

Server componentsCatalog və detail route-ları mümkün qədər server component olaraq saxlanılır.
Client componentsSlider, form, cart, wishlist və seçim tələb edən hissələrdə use client istifadə edilir.

4. Dizayn sistemi

Figma-dan çıxarılan CSS dəyərləri dağınıq şəkildə yazılmayıb, Tailwind theme tokenlərinə çevrilib. Komponentlərdə bu tokenlər utility class kimi istifadə olunur.

TokenDəyərİstifadə

muted#807D7Eİkinci dərəcəli mətnlər
accent#8A33FDButton, active indicator və linklər

Tipografiyada Figma-dakı Causten, Core Sans C, Mintaka və Poppins ailələri theme-də fallback fontlarla birlikdə təyin olunub. Real font faylları ayrıca təqdim edilmədiyi üçün sistem fallback-ləri əlavə edilib.

Build nəticəsi

  • TypeScript yoxlaması uğurla keçir.
  • Production build uğurla tamamlanır.
  • Məhsul route-ları build zamanı static generation ilə hazırlanır.
  • Remote şəkillər üçün images.unsplash.com domeni Next config-də icazəlidir.

Backend üçün növbəti mərhələ

Hazırkı təqdimat versiyasında login, register, cart və checkout məlumatları mock-dur. Real istifadəyə keçid zamanı AuthContext API endpoint-i ilə, CartContext isə database və payment provider ilə əvəz edilə bilər. UI komponentlərinin quruluşu bu inteqrasiyaya uyğun saxlanılıb.
